# Practice exercises

1. Count successful and failed fictional events separately.
2. Validate timestamps using datetime.fromisoformat.
3. Group failures by account and calendar day.
4. Add a JSON report containing aggregate counts, not secrets.
5. Handle missing headers and malformed rows; write tests.
6. Hash a local sample file, edit it and compare with the original trusted digest.
7. Explain why a file digest does not verify its author.
8. Write a short investigation note explaining possible benign causes of repeated login failures.
