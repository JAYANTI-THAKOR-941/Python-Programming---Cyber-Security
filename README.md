# Python Programming for Cybersecurity

Classroom exercises grouped by batch, including Python fundamentals, exception handling and networking examples.

## Project structure

- `12-TO-01/`
- `4 TO 5/`
- `12-TO-01/chat_client.py`
- `12-TO-01/chat_server.py`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/Python-Programming---Cyber-Security.git
cd Python-Programming---Cyber-Security
```

Install Python 3, enter the appropriate batch directory, review imports and run individual exercises. Perform networking experiments only in authorized, isolated labs.
